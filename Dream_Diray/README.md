# Dream_Diary
- 꿈의 내용을 창작 아이디어로 활용할 수 있도록 돕는 모바일 최적화 다이어리

## 제작 목적
- HTML을 활용한 웹 페이지 구조 설계 및 구현
- 창작/기획 소스 활용

## 주요 기능
- **타임라인 분할 (Timeline Split)** : 급변하는 꿈 장면별 시간대·장소·인물을 기록할 수 있습니다.
- **자동 해시태그 (Auto Hashtag)** : 상세 내용을 기반으로 주요 키워드를 자동 추출해줍니다.
- **흐름도 시각화 (Flowchart Visualization)** : 장면 간의 전개 과정을 화살표 흐름도로 한눈에 요약해 줍니다.
- **파일 내보내기 (File Export)** : 꿈 대체목과 연동하여 깔끔한 .txt 메모와 .png 이미지로 저장할 수 있습니다.
- **장르 분류 및 검색 (Genre Classification & Search)** : 일상, SF, 판타지 등 다양한 장르별 필터와 통합 키워드 검색을 지원합니다.
